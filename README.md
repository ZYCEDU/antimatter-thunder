# 反物质雷光炮塔

Mindustry 160.5 独立炮塔模组。以每秒 1 电力发射射程 200 格的穿透雷光。光束沿直线攻击敌方建筑和单位，可对空、对地；沿途的每个命中目标各自承受完整单发伤害。友军不受伤害。

| 模式 | 单发伤害 | 发射间隔 | 每目标持续伤害 | 液体消耗 |
| --- | ---: | ---: | ---: | --- |
| 仅电力 | 1000 | 1 秒 | 1000/秒 | 无 |
| 水 | 2000 | 2/3 秒 | 3000/秒 | 4 水/发 |
| 冷却液 | 3000 | 1/2 秒 | 6000/秒 | 3 冷却液/发 |

以上数值基于满电、连续命中，目标自身的减伤仍适用。水使单发伤害增加 100%、装填速度增加 50%；冷却液使单发伤害增加 200%、装填速度增加 100%。液体只在开火时扣除，持续射击时两种强化各消耗约 6 单位/秒。液体不足自动降档；同时具备两种液体时优先使用冷却液。炮塔不会叠加其他建筑的超速效果。

- 生命值：3000。
- 占地：2×2 格。
- 建造材料：铜、铅、钛、钍各 1000。
- 默认解锁，位于“炮塔”建造分类。

## 导入

在安卓平板上优先用已验证可用的 GitHub 导入方式：解压 ZIP，将 `mod.json`、`scripts/`、`sprites/`、`icon.png` 和 `README.md` 上传到一个公开 GitHub 仓库的根目录并提交。游戏内进入“模组 → 导入模组 → 从 GitHub 导入”，输入 `你的用户名/仓库名`，按提示重启。

如果本地文件导入可用，可直接选择 ZIP，无需解压。安装后可先在塞普罗沙盒放置炮塔并接入电网。此模组使用游戏内置 JavaScript 脚本，无需编译或另外安装运行环境。

## 验证

使用官方 160.5 引擎验证模组导入、建造属性、射程、贯穿伤害、无友伤、三档实际伤害和开火间隔、液体消耗及无电停火。安卓设备上的导入和显示尚未实测。
